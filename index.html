Drop-in · self-hosted

Put the WhatsApp button in any corner.

A configurable build of the official SleekFlow WhatsApp button. Same options, same look — plus a single position option for bottom-right, bottom-left, top-right or top-left. The chat window follows the button, opening upward or downward as needed.

Options

Everything from the official script still works. The rows below are new.

Official options, unchanged: brandName, buttonName, brandSubtitleText, welcomeMessage, phoneNumber, brandImageUrl, callToAction, buttonSize, buttonIconSize, prefillMessage, poweredByColor.

Events & methods

  • widget-opened / widget-closed — custom events dispatched on the element.
  • open(), close(), show(), hide() — available on the element.
  • whatsappButton(options) called again replaces the widget.

Good to know

  • The launcher sits flush with the vertical edge, like the official widget. Set offsetY to clear a sticky header.
  • The panel shrinks on short viewports instead of running off-screen.
  • Styles live in a shadow root, so your page CSS can't clash.
